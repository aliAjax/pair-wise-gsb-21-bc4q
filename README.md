# hxwl-07 缺陷保留与放行台

过站检查发现缺陷后不再只留在演示列表：缺陷全程保留、缺件候补可交接、放行前闸门不通过就停在待办。

## 业务流程

- **缺陷保留**：每项记录机型、机号、ATA 章节、区域、描述、保留类别/期限、责任人与责任班组。
- **缺件候补**：航材没到先转「候件中」，到货后变「到货待复核」，复核通过才关闭；可撤销候补、延长保留期限。
- **交接班**：发起交接后接班人逐条确认接管，未接管的条目即使交接完成仍归原班组；交接过程留痕。
- **放行签署**：放行前检查「该机号未关闭缺陷」和「机位占用窗口冲突」两道闸门；任一不过，签署停在待办并逐条写明原因，原因排除后可对同一条记录再次签署。
- **持久化**：数据写入 localStorage，关闭重开后接着办理；可一键恢复演示数据。

## 代码分层

```
src/
├── data/          # 资料层：类型、参考数据（机型/ATA/区域/机位）、初始演示数据
├── logic/         # 判断层：缺陷流转、交接归属、放行闸门、时间工具（纯函数）
├── store/         # 保存层：reducer + localStorage 外部 store
└── ui/            # 界面层：四个工作台（台账/候补台/交接班/放行台）
```
