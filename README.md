# hxwl-07 缺陷保留与放行台

过站检查发现缺陷后的保留、候补、复核、交接与放行原型。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 功能

- **缺陷保留登记**：机型、ATA章节、区域、描述、保留期限、责任人，超期高亮
- **航材候补流转**：保留中 →（航材缺件）候补待航材 →（航材到货）到货复核 → 关闭；复核不通过退回保留，全程留痕
- **交接班**：接班方对未关闭缺陷逐条确认「接管 / 不接管」，未接管的仍归原班组
- **放行闸门**：放行前校验同机型未关闭缺陷与机位占用冲突，存在阻塞时签署停在待办并逐条写明原因
- **断点续办**：全部数据保存在 localStorage，重开页面接着办理；可一键恢复示例数据

## 代码结构（资料 / 判断 / 保存 / 界面分离）

```
src/
  data/types.ts    资料：领域结构定义
  data/seed.ts     资料：示例数据
  domain/logic.ts  判断：状态机、交接班规则、放行闸门（纯函数）
  store/storage.ts 保存：localStorage 读写
  ui/              界面：登记表单、缺陷清单、交接班面板、放行台
  App.tsx          组装与状态编排
```
